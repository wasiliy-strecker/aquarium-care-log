# PDF-Auswahl umordnen

In der gemeinsamen PDF-Auswahl steht „PDF ohne Fotos erstellen“ jetzt über
„PDF mit Fotos erstellen“. Das gilt für Einzel- und Pflegeverlaufsprotokolle.

Manuelle Nachprüfung: Bei einem Eintrag und beim Pflegeverlauf jeweils
„PDF erstellen“ öffnen und die Reihenfolge prüfen. Ohne vorhandene Fotos
bleibt die zweite Option deaktiviert.

Prüfung: `npm run check` mit Formatprüfung, ESLint, TypeScript und 53 Tests
erfolgreich. ARM64-Dev-APK gebaut und nach Paket- und Signaturprüfung über die
bestehende Installation auf dem HONOR aktualisiert. Die eigenständige Version
benötigt dafür ein neues eingebettetes JavaScript-Bundle. App gestartet,
keine gemeldeten Startfehler. Keine Datenlöschung und kein Push.
