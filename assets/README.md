# Lokale Ressourcen

`aquarium.svg` und `aquarium-foreground.svg` sind die app-eigenen Vektormotive.
Die PNGs werden mit ImageMagick daraus gerendert. Das Vordergrundbild bleibt transparent.
`synthetic-photo.jpg` ist ein gerendertes Testmotiv ohne persönliche Daten.
`ui/` enthält app-lokale Roboto- und MaterialIcons-Schriften aus der Hausakte-Basis.
Die zugehörigen Lizenzen liegen neben den Schriftdateien.
